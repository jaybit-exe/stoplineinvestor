Compounding growth

See how an account grows with steady returns and monthly deposits.

Results

How it works

Compounding means returns earn their own returns. This calculator compounds monthly: balance = start x (1 + r)^n + deposit x ((1 + r)^n - 1) / r, where r is the monthly rate and n the number of months.

Steady deposits matter as much as the rate in the early years. A constant return is an assumption and real returns vary, so use conservative numbers and treat the result as a rough guide.

FAQ

How is compound growth calculated here? The annual return is split into a monthly rate, applied each month to the balance, and the monthly deposit is added each month.

Is the return guaranteed? No. The calculator assumes the same return every month. Real returns vary, and losing years change the result a lot.

Does this include taxes or fees? No. Taxes, fees and inflation all reduce the real ending balance.
